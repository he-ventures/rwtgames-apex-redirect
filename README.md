# rwtgames-apex-redirect

Serves the bare domain rwtgames.com and sends every request to https://www.rwtgames.com with the same path (308/301).
GoDaddy's domain forwarding drops the path (rwtgames.com/osrs gave a 404), so the bare domain points here instead.
The real site is he-ventures/yellow-hat on Railway (www.rwtgames.com).
